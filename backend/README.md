# 🚀 API de Gestión de Usuarios

API desarrollada con Node.js y Express para la creación de usuarios, conectada a una base de datos MongoDB.

---

## 🚀 Guía para usar la API

### ⚙️ Instalación y ejecución del servidor

Sigue los siguientes pasos para configurar y ejecutar el proyecto correctamente:

---

### 📋 Requisitos previos

1. Tener **Node.js** instalado (versión estable recomendada, por ejemplo: v24.12.0)

2. Tener **MongoDB** instalado y en ejecución
   - Asegúrate de que esté activa la conexión por defecto:
     ```
     mongodb://localhost:27017
     ```

---

### 🛠️ Pasos para ejecutar el servidor

3. Descargar o clonar el repositorio

4. Ubicarse en la carpeta del backend

5. Instalar las dependencias del proyecto: con `npm install`

6. Entrar a la carpeta `src` dentro del backend

7. Ejecutar el servidor en modo desarrollo: `npm run dev`

---

### ⚠️ Configuración importante

- Asegúrate de que el puerto **3000** esté disponible
- Verifica que MongoDB esté corriendo correctamente

---

## 📡 Uso de la API

Una vez el servidor esté en ejecución, podrás consumir el endpoint disponible.

### ➕ Crear usuario

- **Método:** POST
- **URL:** http://localhost:3000/users

---
