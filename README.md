# trash-report-system

Creacion del frontend de la pagina detalle reporte basica y con datos de prueba para comprobar que funcione (a falta de backend)

para acceder a la pagina de detalle de reporte ejecute npm run dev dentro de la carpeta web y vaya al enlance http://localhost:****/reports/1 (Los * deben ser remplazados por los 4 digitos del localhost que la terminal le muestre)
